# OCR 교정 규칙

OCR 오인식 교정과 엔진 선택 근거. `src/menu_bot/ocr_provider.py`(엔진 선택)와 `src/menu_bot/corrections.py`(교정 로직)를 건드릴 때 참고한다.

## 엔진 선택: 왜 PP-OCRv5 mobile인가
<!-- akela: scope=ocr-fix tier=should -->

- macOS는 Apple Vision(on-device), Windows/Linux는 PaddleOCR(`PP-OCRv5_mobile_det` + `korean_PP-OCRv5_mobile_rec`)를 로컬 CPU에서 실행한다.
- **PP-OCRv5 server 감지 모델은 쓰지 않는다.** Windows PC에서는 oneDNN 오류로, Linux 서버에서는 세그멘테이션 폴트로 죽는 것을 실측으로 확인했다. 두 환경 모두 mobile 감지 모델만 사용한다.
- 모델명은 `PADDLE_DET_MODEL`, `PADDLE_REC_MODEL`, `PADDLE_ENABLE_MKLDNN` 환경변수로 바꿀 수 있으나, 비워두면 위 mobile 조합이 기본값이다.
- 두 엔진 모두 `{text, confidence, x, y, width, height}` 정규화 좌표(좌하단 원점, y축 위로 증가)로 결과를 맞춰서 파서가 엔진을 구분하지 않고 동작한다.
- Linux 서버(Ubuntu 24.04, Python 3.12)에서 재검증한 결과 날짜·끼니·코너 셀 구성과 휴무/특식 판정이 Apple Vision 기준과 115/115(+1) 일치했다.

## 교정 파이프라인 3단계 (`corrections.py`)
<!-- akela: scope=ocr-fix tier=should -->

1. **노이즈 버리기**: 한글이 한 글자도 없는 항목은 버린다(장식 문구·로고 조각 등).
2. **표기 교정**: 한국어에 없는 표기를 고정 목록으로 바꾼다. 실제 이미지로 PaddleOCR과 Apple Vision을 대조해서 모은 목록이며, 반대로 PaddleOCR이 더 정확했던 표기는 넣지 않는다.
3. **어휘집 교정**: 어휘집에 없고 한 글자만 다른 어휘집 항목이 **정확히 하나**일 때만 바꾼다. 후보가 둘 이상이면 손대지 않는다.

## 어휘집 교정의 하한선: 등장 3회 이상
<!-- akela: scope=ocr-fix tier=should -->

- 어휘집 자체에도 오인식이 섞여 있을 수 있어(Apple Vision이 잘못 읽은 값이 그대로 들어감), **등장 3회 이상**인 항목만 교정 후보로 쓴다.
- 오인식은 보통 한두 번만 나타나고 실제 메뉴 이름은 여러 번 반복되기 때문이다. 하한이 없으면 올바로 읽은 `부추잡채`가 1회만 등장한 오인식 `부주잡채`로 되돌아가는 사고가 생긴다.
- 어휘집은 실제 메뉴 데이터이므로 공개 저장소에 넣지 않는다(`data/`는 git 제외). `menu-bot build-vocab`으로 학습용 게시물 목록에서 직접 만든다. 파일이 없으면 어휘집 층만 조용히 꺼지고 노이즈·표기 교정은 그대로 동작한다.

## 대표 오인식 패턴 (patterns)
<!-- akela: scope=ocr-fix tier=should -->

- `숭늉`(1년치 최다 등장 항목, 466회)이 `숭능`·`숭융`·`승능`으로 오인식되는 경우가 가장 흔하다.
- `장`(醬) 계통 글자가 `정`·`자`·`창`·`작`·`당`·`중`·`짱`·`잠`으로 읽히는 오류가 1년치 68건 중 가장 큰 비중을 차지했다.
- 장식 서체 줄에서 `004`, `oo` 같은 짧은 노이즈 조각이 드물게 끼어든다.

## 신뢰도 임계값을 쓰지 않는 이유 (no-threshold)
<!-- akela: scope=ocr-fix tier=must -->

- OCR 신뢰도로 노이즈를 걸러내려 시도했으나 쓸 수 없었다: 노이즈 `oo`의 신뢰도가 0.67인데 정상 항목 `숭늉`은 0.40~0.82로 흩어져 있어, 노이즈를 지우는 임계값이 정상 메뉴를 먼저 지운다(실측 615줄 중 89줄이 0.5 미만).
- 따라서 임계값 기반 필터링은 넣지 않고, 위 3단계 교정 파이프라인만 사용한다.

## 측정된 효과 (measured-results)
<!-- akela: scope=ocr-fix tier=context -->

- 1년치에서 고르게 뽑은 실제 이미지 25장(셀 311개) 기준, 교정 전 173/311(56%) 불일치 → 교정 후 78/311(25%) 불일치로 개선. 새로 어긋난 셀은 0개.
- 셀 구성과 휴무/특식 판정은 교정 전후 모두 311/311 일치 — 글자 단위 오차가 판정 로직에 영향을 주지 않는다.
- 남는 한계: 끼어든 조각이 한글로 이루어진 경우(예: 장식 줄에서 온 `해지공탕`)는 노이즈 규칙에도, 어휘집 한 글자 차이 규칙에도 걸리지 않아 그대로 남는다.
