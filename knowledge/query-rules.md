# 질의 해석 규칙

챗봇(`src/menu_bot/query.py`)이 카카오톡 발화를 어떻게 해석하는지 정리한 규칙. 새 발화 패턴을 추가하거나 회귀를 디버깅할 때 참고한다.

## 요일 해석 (weekday)

- 월~일 어느 요일을 말해도 항상 "이번 주" 날짜로 해석한다. 다음 주는 지원하지 않는다.
- `다음주`, `담주`, `차주`가 섞인 요청은 제공하지 않고, 이번 주 식단만 조회할 수 있다고 안내한다.
- `토`, `일`, `토요일`, `일요일`은 식당이 운영되지 않는다고 안내한다.
- 과거 식단 조회는 지원하지 않는다(1년치 데이터는 파서 검증 전용).

## 끼니 해석 (meal)

- `아침`, `점심`, `저녁`만 말하면 오늘 해당 끼니를 보여준다.
- `월`, `월요일`처럼 끼니 없이 요일만 말하면 그날의 조식·중식·석식 전체를 끼니별 말풍선으로 나눠 보여준다.
- `이번주 점심`처럼 요일이 빠진 질문은 오늘 식단으로 자동 대체하지 않고 요일 입력을 안내한다.

## 줄임말·구어체 (abbreviations)

- `금욜`, `낼점심`, `담주월 아침` 같은 일상적인 줄임말을 인식한다.

## 코너 이름 질의 (corner-query)

- `간편식`, `건강식`처럼 코너 이름만 말하면 그 코너가 나오는 끼니로 매핑해서 보여준다: 간편식→조식, 건강식→중식(1년치 실데이터에서 다른 끼니 등장 0회로 확인된 매핑).
- 세 끼니에 모두 나오는 `일반식`·`PLUS`(표시명은 `공통 PLUS`)는 끼니를 되묻는다.

## 모호성·오류 처리 (ambiguity)

- 모르는 낱말이 섞이면(예: `오늘 커피`) 그날 전체 식단으로 임의 대체하지 않고, 못 알아들은 낱말을 되짚어주며 사용법을 안내한다.
- 날짜·요일·끼니가 둘 이상 섞이거나 잘못된 날짜가 들어오면 임의로 하나를 선택하지 않고 다시 묻는다.

## 응답 형식 (response-format)

- 모든 답변에 실제 날짜를 표시한다(예: `08월 21일(금)`).
- 메뉴는 코너별 세로 목록으로, 하루 전체 조회는 끼니별 말풍선으로 나눈다.
- 모든 응답에 `오늘의 아침`·`오늘의 점심`·`오늘의 저녁`·`사용방법` 퀵 리플라이 버튼을 포함한다. 오늘 끼니 버튼은 입력 없이 바로 해당 끼니를 조회한다.
